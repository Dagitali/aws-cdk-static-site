# AWS CDK Static Site v0.1.2

Version 0.1.2, tagged on 2026-09-07, adds an explicit region safeguard for managed certificates.

See the [changelog] for the release entry.

- [Highlights](#highlights)
- [Compatibility and Operations](#compatibility-and-operations)
- [Validation](#validation)

## Highlights

- Rejected construct-managed CloudFront certificate creation unless the stack region is `us-east-1`.
- Added synthesis-time validation, regression tests, changelog coverage, and configuration guidance
  for the region requirement.

## Compatibility and Operations

Consumers creating certificates through the construct had to target `us-east-1`; imported
certificates and deployments without a custom domain were unaffected. The guard fails before
deployment and therefore does not itself replace AWS resources.
