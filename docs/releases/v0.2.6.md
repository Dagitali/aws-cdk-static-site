# AWS CDK Static Site v0.2.6

Version 0.2.6, tagged on 2026-09-08, expanded examples, local documentation, and reusable project
conventions.

- [Highlights](#highlights)
- [Compatibility and Operations](#compatibility-and-operations)

## Highlights

- Added independently synthesizable examples for generated hostnames, external DNS, Route 53, access
  logging, external content, and customized security policy.
- Added a local Sphinx site with API documentation and strict CI validation.
- Standardized package metadata, documentation tooling, and contributor-facing guidance.

## Compatibility and Operations

The added examples and documentation were additive. Read the Docs publication remained deferred, and
consumers retained responsibility for selecting and deploying an appropriate configuration.
