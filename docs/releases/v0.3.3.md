# AWS CDK Static Site v0.3.3

Version 0.3.3, tagged on 2026-09-09, removed private consumer coupling and repaired release
publication safeguards.

- [Highlights](#highlights)
- [Compatibility and Operations](#compatibility-and-operations)

## Highlights

- Removed the private `dagitali.com` checkout, consumer test, and corresponding CI and Make targets.
- Ran local Python-policy and workflow-pin hooks in managed pre-commit environments.
- Restored release validation dependencies, exact-tag GitHub Release recovery, and versioned README
  installation-snippet checks used at the time.
- Aligned testing, contribution, workflow, and branch-protection documentation.

## Compatibility and Operations

The reusable package no longer depended on access to a private consumer repository for validation.
Construct behavior and synthesized infrastructure were unchanged; maintainers gained a
self-contained release gate and an exact-tag recovery path that did not move published tags.
