# AWS CDK Static Site v0.2.1

Version 0.2.1, tagged on 2026-09-08, automates validated GitHub release publication.

See the [changelog] for the release entry.

- [Highlights](#highlights)
- [Compatibility and Operations](#compatibility-and-operations)
- [Validation](#validation)

## Highlights

- Adds tag-triggered GitHub Releases with once-built source and wheel distributions.
- Adds isolated artifact smoke tests, SHA-256 checksums, and a CycloneDX dependency SBOM.
- Harmonizes supporting CI, documentation, and release-lifecycle guidance.

## Compatibility and Operations

The release changed publication automation rather than the construct API or synthesized resources.
Artifacts were published to GitHub Releases; PyPI publication remained intentionally inactive.
