# AWS CDK Static Site v0.3.4

Version 0.3.4, tagged on 2026-09-09, standardized Python formatting around single quotes.

- [Highlights](#highlights)
- [Compatibility and Operations](#compatibility-and-operations)

## Highlights

- Configured Ruff to prefer single quotes, including nested Python 3.13 f-string expressions.
- Applied the policy consistently across Python code and documentation examples.

## Compatibility and Operations

This formatting release did not intentionally change package behavior or synthesized AWS
infrastructure. Contributors needed to use the updated formatting policy; consumers required no
migration.
