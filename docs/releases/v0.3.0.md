# AWS CDK Static Site v0.3.0

Version 0.3.0, tagged on 2026-09-08, added layered validation from package artifacts through a
bounded disposable AWS deployment.

See the [changelog] for the release entry.

- [Highlights](#highlights)
- [Compatibility and Operations](#compatibility-and-operations)
- [Validation](#validation)

## Highlights

- Added wheel and source-distribution content, metadata, installation, import, typing-marker, and
  CDK synthesis tests.
- Added explicit example synthesis, consumer compatibility, and optional `cdk-nag` validation.
- Added a manually approved, OIDC-authenticated deployment test with a fixed resource allowlist,
  unique stack name, cost boundaries, and automatic cleanup.
- Standardized test layers, pre-commit automation, and local/hosted CI gates.

## Compatibility and Operations

Package behavior remained backward compatible, but maintainer validation expanded substantially. The
AWS deployment test was opt-in and manual; it required a protected environment and dedicated,
least-privilege OIDC role and could incur short-lived S3 and CloudFront charges.
