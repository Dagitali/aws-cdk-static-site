# AWS CDK Static Site v0.1.3

Version 0.1.3, tagged on 2026-09-08, established a tested Python support contract.

- [Highlights](#highlights)
- [Compatibility and Operations](#compatibility-and-operations)

## Highlights

- Limited package support to Python 3.13 and 3.14.
- Aligned package metadata, local tooling, CI, validation, and documentation with that range.

## Compatibility and Operations

Python versions outside 3.13 and 3.14 were no longer supported. The release changed no construct
inputs or synthesized AWS resources, so no infrastructure migration or rollback was required.
