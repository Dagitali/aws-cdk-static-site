# AWS CDK Static Site v0.3.12 (Planned)

The planned version 0.3.12 updates the Ruff executable used by the repository's pre-commit hook. No
`v0.3.12` tag has been created yet.

## Highlights

- Updates the `ruff-pre-commit` revision from v0.16.6 to v0.16.7 through [Dependabot pull request
  6].
- Incorporates [upstream Ruff fixes] for nested quotes in format-spec interpolations and the `UP035`
  recommendation for the removed `typing.no_type_check_decorator`, together with rule and
  performance improvements.
- Retains the `ruff-check` hook, automatic fixes, fail-on-fix behavior, Python 3.13 target, selected
  `B`, `E`, `F`, `I`, `UP`, and `W` rules, 88-character line length, and single-quote policy.
- Does not enable Ruff's preview rules or the separately configured `ruff-format` hook.

## Change Scope

This release changes only the `rev` value for `https://github.com/astral-sh/ruff-pre-commit` in
`.pre-commit-config.yaml`. Pre-commit installs the mirrored Ruff executable in its own managed
environment; the package source, runtime dependencies, public API, examples, tests, and synthesized
AWS infrastructure are unchanged.

The development dependency remains the compatible `ruff>=0.16,<0.17` range in `pyproject.toml`.
Ruff's rule selection, exclusions, target version, formatter configuration, and hook arguments also
remain unchanged.

## Compatibility and Configuration

No consumer compatibility or configuration changes are required. Contributors may see pre-commit
initialize or refresh its managed Ruff environment on the next hook run.

## Support Boundary

No Python, AWS CDK, stability, package, or infrastructure-support boundary changes in this release.

## Validation

- `pre-commit run --all-files` passes with the updated mirror revision without applying fixes.
- `make check` passes with repository policy checks, Ruff, mypy, 65 unit and integration tests, 100%
  measured coverage, distribution builds, and `twine check`.
- All nine GitHub Actions checks reported for [Dependabot pull request 6] passed, including the
  supported-Python dependency matrix, cross-platform installation smoke tests, package validation,
  and distribution validation.
- The Ruff update produces no source or synthesized-template changes.

## Deployment and Rollback

Merging this release into `main` runs ordinary CI but does not deploy AWS resources. Creating the
`v0.3.12` tag triggers release-artifact publication; the wheel's runtime package contents and
runtime dependencies are unchanged.

If the updated hook causes a contributor-workflow regression, restore the v0.16.6 revision through
the normal reviewed hotfix process and allow pre-commit to recreate its managed environment. No
package downgrade, AWS deployment, resource replacement, or infrastructure rollback is required.

## Known Limitations and Follow-Up

- The pre-commit mirror and the Ruff development dependency are resolved through separate
  environments, although both remain within the repository's 0.16-compatible policy.
- Ruff 0.16.7 includes preview rules that remain inactive because this repository neither enables
  preview mode nor selects the `RUF` rule family.
