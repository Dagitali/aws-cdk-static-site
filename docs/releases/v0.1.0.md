# AWS CDK Static Site v0.1.0

Version 0.1.0, tagged on 2026-09-07, delivered the initial usable package and repository lifecycle.

- [Highlights](#highlights)
- [Compatibility and Operations](#compatibility-and-operations)

## Highlights

- Added the `StaticSite` construct and its typed properties under the `src/` package layout.
- Added private S3 storage, CloudFront delivery, optional content deployment, custom-domain support,
  security headers, access logging, and Route 53 integration.
- Added the basic example, unit tests, CI and SBOM workflows, package metadata, maintenance checks,
  contributor guidance, security policy, and release documentation.

## Compatibility and Operations

This was the first pre-1.0 package release, so no package migration was required. Consumers remained
responsible for CDK app configuration, AWS credentials, deployment identity, and site content.
