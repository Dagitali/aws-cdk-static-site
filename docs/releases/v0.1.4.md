# AWS CDK Static Site v0.1.4

Version 0.1.4, tagged on 2026-09-08, strengthened replacement-safety regression coverage.

- [Highlights](#highlights)
- [Compatibility and Operations](#compatibility-and-operations)

## Highlights

- Added selective logical-ID assertions for stateful S3 resources.
- Retained property-based assertions for resources whose generated identities were not part of the
  replacement-safety contract.

## Compatibility and Operations

This test-only release did not intentionally change package behavior or synthesized templates. It
made accidental future replacement of stateful resources easier to detect before deployment.
