# AWS CDK Static Site v0.2.0

Version 0.2.0, tagged on 2026-09-08, added opt-in immutable-asset deployment with long-lived cache
metadata.

- [Highlights](#highlights)
- [Compatibility and Operations](#compatibility-and-operations)

## Highlights

- Added an immutable-asset deployment path with long-lived cache metadata while preserving
  revalidation for HTML and other mutable content.
- Added immutable-asset path and cache-duration properties with validation and regression coverage.
- Preserved the existing mutable-content deployment path when immutable assets were not configured.

## Compatibility and Operations

The immutable-asset behavior was opt-in; existing mutable-content deployments retained their cache
policy. Consumers enabling immutable assets needed content-hashed filenames and should review cache
invalidation expectations before deployment.
