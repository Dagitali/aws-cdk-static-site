# AWS CDK Static Site v0.3.7

Version 0.3.7, tagged on 2026-09-10, consolidated repository-maintenance utilities behind a reusable
command-line interface.

- [Highlights](#highlights)
- [Compatibility and Operations](#compatibility-and-operations)

## Highlights

- Added shared script support and verb-oriented `python -m scripts` commands used by Make,
  pre-commit, and GitHub Actions.
- Added validation for duplicate dependency declarations and reversed README markers.
- Expanded regression coverage for repository policy utilities.

## Compatibility and Operations

This maintainer-tooling refactor preserved package behavior and existing validation intent. It
changed no construct API or synthesized AWS infrastructure and required no consumer action.
