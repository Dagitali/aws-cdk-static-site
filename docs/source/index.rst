AWS CDK Static Site
===================

``aws-cdk-static-site`` is a Python AWS CDK construct for serving a static
website through CloudFront from a private, encrypted S3 bucket.

This compact documentation site provides an installation path, focused
composition examples, and an API reference generated from the package source.
It is built and viewed locally; publishing through Read the Docs is deferred
until the package has a regular PyPI release lifecycle.
